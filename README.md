# AI & ML Learning Projects

Welcome to my repository containing a collection of AI and ML projects aimed at solving real-life problems. These projects are part of my learning journey and span a variety of domains, each with its own approach and challenges. Some projects include a UI for easy interaction, while others focus purely on code. All of them are runnable and immediately applicable.

### Projects in this Repository:
- **EnergyConsumptionTimeSeries**: Time series forecasting of energy consumption.
- **fluid_simulation**: Simulating fluid dynamics using machine learning.
- **FLY_project**: Predicting flight delays using a Decision Tree Classifier.
- **NLP-trackless-extension**: An NLP-based anti-tracking solution to detect tracking URLs.
- **suppy_optimization**: Optimization of supply chain operations using ML techniques.

Feel free to explore the projects, and if you have any questions or suggestions, do not hesitate to reach out to me!
